# Bank Account Simulator

The Bank Account Simulator is a simple Java program that allows users to manage a virtual bank account through a menu-based interface. Users can check their account balance, deposit money, withdraw money, and view their transaction history. The program uses object-oriented programming and Java's ArrayList collection to manage account information and store transactions.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install the Java Development Kit (JDK) and a Java IDE such as IntelliJ IDEA or Visual Studio Code.
2. Create a Java project and add the `Main.java` and `BankAccount.java` files.
3. Compile and run the `Main.java` file to start the program.

Instructions for using the software:

1. Start the program to display the bank account menu.
2. Select an option to view your balance, deposit money, withdraw money, or view transaction history.
3. Follow the prompts to enter amounts or view account information.
4. Select the exit option when finished.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Java Development Kit (JDK) 17 or newer.
* Visual Studio Code or IntelliJ IDEA.
* Java ArrayList library (`java.util.ArrayList`), included with the JDK.
